# 나이스 그리드 낭독 비교

4세대 나이스(NEIS) 그리드의 칸 이름(aria-label)에 행 번호·경계·열 이름이 문자열로 합성되어 스크린리더가 칸마다 같은 말을 반복하는 문제를, 같은 표의 두 버전으로 비교하는 정적 페이지입니다.

- 현재 나이스: 교육용 서버(edu.neis.go.kr)에서 실측한 aria-label 문자열을 그대로 재현
- 개선안: 그 문자열을 지우고 표준 ARIA 속성(role, aria-rowindex, aria-colindex, columnheader)만 남김

배포: GitHub Pages. 빌드 없이 `index.html`, `app.js`, `data.js`, `compose.js`, `styles.css`만으로 동작합니다.

값은 교육용 서버의 테스트 데이터이며 계정 ID는 가린 값입니다.

## 사용법

- Tab으로 표에 들어가면 나이스와 같이 표 컨테이너(role=grid)가 먼저 포커스를 받고(스크린리더가 표 이름과 진입 안내를 읽는 지점), 방향키로 칸에 들어감. 칸에서 Tab/Shift+Tab은 표 밖으로 나감
- 방향키로 칸 이동, Home/End로 행의 처음과 끝, Ctrl+Home/End로 표의 처음과 끝, 스페이스로 행선택 체크박스 토글
- 「개선안으로 전환」 버튼 또는 표 안에서 V 키: 보던 칸에 포커스를 유지한 채 버전 전환
- 행 소유 관계도 재현한다. 현재 나이스는 표와 행 사이에 역할 없는 컨테이너가 끼어 있어(2026.09.15 실측: 행이 그리드 8단계 아래, 중간에 role=group 하나) 스크린리더가 표 크기를 세지 못한다. 개선안은 rowgroup이 행을 거느린다
- 「읽기」 버튼(accesskey R) 또는 표 안에서 R 키: 브라우저 음성 합성(Web Speech API)으로 칸 이름을 읽음. 자동 읽기를 켜면 표에 들어갈 때 센스리더 실측 진입 문구도 함께 읽음
- 낭독 패널: 포커스한 칸의 이름, 역할과 상태, 표준 속성, 표 진입 시 낭독 문구, 마크업, 같은 행 전체의 이름 목록을 표시
